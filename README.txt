bitfire2crt — перевод трекмо-демок на загрузчике Bitfire в картридж EasyFlash (.crt)
====================================================================================

Как это работает
----------------
1. t4.py      — эмулирует бутер (распаковщик) и снимает образ распакованного инсталлятора
               ($8000-$8C2B) -> dec_mem.pkl
2. harvest.py — эмуляция C64 + 1541 (своя, на Python: 6502, VIA, GCR-дорожки, шина IEC).
               Через настоящий код дисковода Bitfire запрашивает каждый файл по номеру
               и записывает, что пришло в память (адрес, данные). Так получается «истина»
               для каждой стороны: harvest_a/b/c.pkl
                   python3 harvest.py a 73 ; python3 harvest.py b 56 ; python3 harvest.py c 54
               (число файлов = записи в каталоге 18/18 (+18/17); формат: адрес-$100, длина-1)
3. build_crt.py — собирает CRT:
     * банк 0: образ инсталлятора, в котором пропущены заливка кода в дисковод и
       ожидание дисковода; RESET-код (ultimax) -> IOINIT/RAMTAS/RESTOR/CINT -> $8A00
     * в резиденте Bitfire заменены только две точки входа:
         $020C (send byte: $EF = следующий файл, <$EF = номер, $F0+n = сторона n)
         $022E (приём блока) -> копирование целого файла из ROM; распаковщик Bitfire оригинальный
     * код загрузчика: $0231-$0286 (свободное место от старого приёма) + RAM EasyFlash $DF00
     * ROM виден только в коротком окне ($01=$37 при SEI); NMI в этом окне ловится через
       ($0318) и передаётся обработчику демки, байт перечитывается
     * файлы всех сторон подряд с банка 1, таблица в банке 0 ($A000)
4. tseq.py    — проверка: загрузка с картриджа и распаковка всех файлов в порядке демки
               со случайными NMI/IRQ, побайтное сравнение с эталоном из эмуляции диска.

Ограничения
-----------
* Адреса патчей ($800C, $803A, $818C, $8150, смещение резидента $80B1, вход $8A00)
  взяты из бутера ЭТОЙ демки. Для другой демки на Bitfire той же версии их нужно сверить,
  а для других загрузчиков (Krill, Spindle, Sparkle и т.д.) нужен свой адаптер.
* Пути к файлам в скриптах прописаны жёстко (/home/claude/work, /home/claude/in/demo).
* Нужен только Python 3, без внешних библиотек.
